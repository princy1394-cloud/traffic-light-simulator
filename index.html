A SHORT FIELD GUIDE MODEL NOTES

How to read the flow

Follow one signal cycle, then watch the same direction indices carry each vehicle from arrival to clearance.

A

Using the simulator

  1. StartBegins the clock and timed arrivals. Vehicles appear at staggered intervals.
  2. ObserveNorth and south share a green phase, followed by amber and a brief all-red clearance. East and west then take their turn.
  3. AdjustChoose a speed to scale simulation time, or select an approach and add a vehicle. Each approach is limited to four vehicles.
  4. Pause / resume / resetPause freezes the model; resume continues it. Reset clears time, queues, and completed counts.
  5. CompareRead the approach totals and array inspector together. Index 00 always means NORTH, 01 EAST, 02 SOUTH, and 03 WEST.
B

Why indexed arrays fit

There are four fixed approaches with the same kinds of measurements. Keeping those values at a shared index lets one loop apply a signal phase to every approach instead of maintaining four separate sets of code.

for (let direction = 0;
     direction < DIRECTIONS.length;
     direction += 1) {
  signalStates[direction] =
    phase.green.includes(direction)
      ? phase.state
      : SIGNAL.RED;
}

The vehicle queues are arrays of vehicle objects—one queue per approach. Their current positions and speeds produce the waiting count and density; completed vehicles increment the matching vehiclesPassed index. The inspector displays these live values, not an example dataset.

i Arrays suit the fixed, ordered directions. Each vehicle is an object because it needs several properties, such as position, speed, and wait time.
